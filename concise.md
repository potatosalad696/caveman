# Concise Guide to Caveman
## Key Terms
### Variables
| Key     	| Meaning                     	|
|---------	|-----------------------------	|
| say     	| String                      	|
| fingers 	| Integer, float              	|
| yesno   	| Boolean                     	|
| bag     	| List, array                 	|
| any     	| Say, fingers, yesno, or bag 	|

### Strings

| Key    	| Meaning                        	|
|--------	|--------------------------------	|
| ""     	| String, double blanket ignored 	|
| "[[]]" 	| String, double blanket used    	|

## Syntax
```
scream ("") !!!
shout ("[[]]" - any) !!
```
